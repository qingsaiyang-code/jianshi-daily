# 知识数据与来源

- `knowledge.json`：从用户提供的旧版初始知识包迁入的 30 条中文种子内容，保留各条来源链接。旧包没有公开新闻日期，本项目按 2026-10-24 / 25 / 26 分组演示日期筛选。
- `special-seeds.json`：新增 3 条专区示例。引用分别指向 NIST 的生成式 AI 风险框架、NATO 的国防支出说明和 BLS 的 CPI 问答；均为中文概述与辅助解释，不是原文转载或实时新闻。来源页面在 2026-10-26 查阅。

所有数据均标记为 `contentKind: seed`，归档日期不代表来源发布时间。这些数据不是自动抓取、自动核查或每日自动生成的结果。旧版 30 条内容沿用交接包的来源，本轮未重新逐条核验其全部科学论断。

新区摘要的计数规则为：去除空白后按 Unicode 码点计算 200–300 字符。旧版内容保留“摘要 + 原理 + 应用”的完整结构，所以不强行截断到相同长度；未来自动生成的卡片按新契约执行。

知识类型见 `src/lib/knowledge.ts`，分类见 `src/lib/taxonomy.ts`。测试检查层级匹配、唯一 ID、日期、来源格式、全文筛选和专区摘要长度；URL 格式测试不等于来源事实已经验证，也不保证未来链接永不失效。

自编中文说明随本项目 MIT 许可提供；外链机构的原始材料、标识和网站内容不被本项目重新许可。引用外部事实时保留对应来源。

`scripts/import-legacy.mjs` 为一次性导入工具，显式读取指定文件，默认写入独立的 `data/imported-legacy.json`；若目标存在会拒绝覆盖。它不会连接 Sites、读取私有数据库或更改运行中的知识库。
